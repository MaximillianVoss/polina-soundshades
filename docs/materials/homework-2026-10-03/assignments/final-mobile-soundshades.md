# Mobile Programming — Final project / идея SoundShades

Источник: `sources/final_tasks.pdf`, страница 1. Условие преподавателя и идея из документа разделены ниже.

## Требования преподавателя

The final project is a mobile application of your own topic. The topic has to be sent for approval to the teacher to make sure in advance that it fulfills the final project requirements and on the other hand is not overly laborious.

Final project submission consists of:

- source code and documentation in a Git repository online;
- learning diary;
- demonstration of the application including review of the implementation: component structure, used features, code walkthrough.

The extent of the application, the variety of used technologies and level of finishing affect the grading.

Projects from previous courses: https://juhahinkula.github.io/hhmobile/

## Предложенная в документе идея, не подтверждение согласования

**SoundShades** — приложение, где пользователи рисуют пиксель-арт о том, как они чувствуют песню, и делятся им. Другие могут смотреть работы и слушать песню.

- Регистрация и вход.
- Выбор песни.
- Рисование пиксель-арта.
- Публикация в ленте.
- Просмотр чужих работ.
- Лайки и комментарии? В оригинале стоит вопросительный знак.
- Свои работы в профиле.

Предложенные технологии: React Native + Expo, Firebase (Auth + Realtime Database), React Navigation, Axios, AsyncStorage, Expo Camera, Expo Notifications, React Native Paper.

## Границы известного

Это одна итоговая работа, не десять отдельных заданий по числу библиотек. Список технологий находится в блоке идеи: обязательность каждой библиотеки преподавателем не подтверждена. Нет конкретной даты сдачи, количественной шкалы баллов или подтверждения утверждения темы.
